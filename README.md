### AI plugin for vim classic

`:Ai` then query or `:Ai query`.

It uses openrouter, `OPENROUTER_API_KEY` to be provided in your environment (preferably from a vault!)

It knows to respond in scratch buffer or in line.

By default it does not see the code, make a VISUAL selection before querying to send the code.

Developed with muse-ember.

#### Requirements

vim-classic or vim8+; openrouter API key.

I use it quite a bit and it's handy, so, sharing.
